1. 最小完整程式

先讀語法

#include <iostream>

int main() {
    敘述;
    return 0;
}

#include <iostream> 引入輸入輸出宣告。main 是執行入口；函式細節留到 P3。大括號圈出區塊，多數敘述以分號結尾。std:: 表示名稱來自標準函式庫。

完整例子與逐行說明

#include <iostream>

int main() {
    std::cout << "歡迎使用結帳程式\n";
    return 0;
}
預期輸出
歡迎使用結帳程式

先準備 iostream；進入 main；std::cout << 把右側文字送到螢幕；\n 換行；最後以 0 表示正常結束。

2. 編譯後才執行

先將上面的完整程式存成 main.cpp，在該檔案所在的資料夾執行下面的指令。後續每支含 main() 的完整範例都分開執行，換例子時替換檔案內容即可。

g++ -std=c++17 -Wall main.cpp -o main.exe
# Windows PowerShell
.\main.exe
# Linux / macOS
./main.exe

編譯指令會檢查並翻譯 main.cpp，產生名為 main.exe 的執行檔。Windows PowerShell 使用 .\main.exe 執行；Linux 或 macOS 使用 ./main.exe 執行。修改原始碼後要重新編譯。

3. 變數、基本型別與 const

先讀語法

型別 名稱 = 初始值;
const 型別 名稱 = 初始值;

int 存整數、double 存小數、char 存單一字元、bool 存 true 或 false。區域變數要先初始化再讀取；未初始化值沒有可依賴的固定結果。char grade = 'A'; 的單引號包一個字元；輸出文字使用雙引號。也可寫 double weight = 2.5; 與 bool paid = false;。

#include <iostream>

int main() {
    const int unitPrice = 35;
    int quantity = 3;
    std::cout << "單價 " << unitPrice
              << "，數量 " << quantity << "\n";
    return 0;
}
預期輸出
單價 35，數量 3

unitPrice 不再改動，所以加上 const；quantity 之後可以重新指定。

4. cout 輸出，cin 輸入

先讀語法

std::cout << 值;
std::cin >> 變數;

<< 把資料送往螢幕；>> 把鍵盤資料送進變數。兩者都能連接多個項目。

範例輸入：35 3

#include <iostream>

int main() {
    int unitPrice = 0;
    int quantity = 0;
    std::cout << "請輸入單價與數量：";
    std::cin >> unitPrice >> quantity;
    int total = unitPrice * quantity;
    std::cout << "總價：" << total << "\n";
    return 0;
}
預期輸出
請輸入單價與數量：總價：105

5. 運算與型別轉換

+ - * / % 做加、減、乘、除與整數餘數。若要把計算結果存回同一個變數，可寫 x += 5;，等同 x = x + 5;。兩個 int 相除會捨去小數；需要小數時先轉換其中一邊。語法 static_cast<目標型別>(值) 中，尖括號指定要轉成的型別，小括號放要轉換的值。

#include <iostream>

int main() {
    int total = 100;
    int people = 3;
    std::cout << "每人 " << total / people << " 元\n";
    double exact = static_cast<double>(total) / people;
    std::cout << "小數結果 " << exact << " 元\n";
    return 0;
}
預期輸出
每人 33 元
小數結果 33.3333 元

互動：結帳程式流程

宣告並初始化單價、數量
從鍵盤讀入兩個整數
計算 unitPrice * quantity
輸出總價並結束

6. 常見錯誤

漏分號

#include <iostream>
int main() {
    int quantity = 3
    std::cout << quantity << "\n";
    return 0;
}

錯誤位置可能指向下一行，先檢查上一行結尾。

使用未宣告名稱

#include <iostream>
int main() {
    std::cout << total << "\n";
    return 0;
}

檢查拼字，並確認名稱已在使用前宣告。編譯成功仍可能算錯；依序檢查輸入、運算式與輸出變數。

動手預測

若單價為 48、數量為 2，總價是多少？若把兩者讀入順序交換，變數會各自拿到什麼？

提示與答案

先追蹤 std::cin >> unitPrice >> quantity; 的方向。正確順序總價是 96；交換變數順序後，unitPrice 會拿到 2、quantity 會拿到 48。

P1 速查

std::cout << 值; 輸出；std::cin >> 變數; 輸入；兩個整數相除會捨去小數；需要小數時在運算前使用 static_cast<double>。
