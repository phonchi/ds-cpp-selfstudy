PART 01

public 繼承與父類別建構式

class Email : public Notification 表示 Email 公開繼承 Notification。子類別建構式的初始化串列用 Notification(text) 先建立父類別部分。

#include <iostream>
#include <string>
class Notification{
  private:
  std::string text;
  public:
  Notification(std::string t) : text(t) {
  }
  std::string getText() const {
    return text;
  }
};
class Email:public Notification{
  public:
  Email(std::string t):Notification(t){
  }
  void send()const{
    std::cout<<"通知："<< getText()<<'\n';
  }
};
int main(){
  Email e("會議開始");
  e.send();
}
預期輸出
通知：會議開始

練習：指出先執行哪一個建構式。

PART 02

virtual、override 與基底參考

父類別函式加 virtual，子類別以相同簽章加 override。函式接受父類別參考時，仍會依實際物件呼叫正確版本。

#include <iostream>
#include <string>
class Notification{
  private:
  std::string text;
  public:
  Notification(std::string t) : text(t) {
  }
  std::string getText() const {
    return text;
  }
  virtual ~Notification() {
  }
  virtual void send()const{
    std::cout<<"通知: "<< getText()<<'\n';
  }
};
class Email:public Notification{
  public:
  Email(std::string text) : Notification(text) {
  }
  void send() const override{
    std::cout<<"Email: "<< getText()<<'\n';
  }
};
class SMS : public Notification {
  public:
  SMS(std::string text) : Notification(text) {
  }
  void send() const override{
    std::cout<<"SMS: "<< getText()<<'\n';
  }
};
void deliver(const Notification& n){
  n.send();
}
int main(){
  Email e("系統更新");
  SMS s("系統更新");
  deliver(e);
  deliver(s);
}
預期輸出
Email: 系統更新
SMS: 系統更新

virtual ~Notification() {} 是空的虛擬解構式。基底類別可能用於多型時，這樣能確保未來透過基底介面銷毀物件時，子類別也會正確收尾。

比較練習：若要觀察非 virtual 的行為，必須同時移除父類別 send 前的 virtual 與子類別的 override；只移除 virtual 會因 override 檢查而編譯失敗。

PART 03

函式模板

template<typename T> 把型別留成參數；呼叫時編譯器依引數產生合適版本。

#include <iostream>
#include <string>
template<typename T>
T larger(T a, T b) {
  if (a < b) {
    return b;
  }
  return a;
}
int main(){
  std::cout << larger(7, 3) << '\n';
  std::cout << larger(2.5, 4.0) << '\n';
}
預期輸出
7
4

練習：用兩個 double 呼叫 larger。

PART 04

類別模板 Box

類別模板讓同一個類別保存不同型別。使用時寫出型別，例如 Box<int>。

#include <iostream>
#include <string>
template<typename T> class Box{
  T value;
  public:
  Box(T v):value(v){
  }
  T get()const{
    return value;
  }
};
int main(){
  Box<int> a(42);
  Box<std::string> b("完成");
  std::cout<<a.get()<<'\n'<<b.get()<<'\n';
}
預期輸出
42
完成

練習：建立 Box<double> 並印出內容。

template<typename T>宣告型別參數，T 在模板內代表一種型別。
