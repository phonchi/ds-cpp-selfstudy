# 先備頁語氣與獨立讀者複查

本輪以發布版 `f5d7772` 為起點，使用 speak-human-tw 的保真與台灣繁中原則，修正 P1–P9。
範圍包含正文、收合說明、圖說、速查表、JavaScript 動態文字、題庫回饋與字卡。
正課與課前準備頁沒有更動。先前驗證紀錄描述的是當時版本，不能代替本輪閱讀。

## 語氣處理

| 原有說法 | 問題 | 本輪處理 |
|---|---|---|
| g++ 罵人的話、編譯器怎麼罵你 | 將診斷擬人化為責罵 | 改為閱讀診斷、編譯器如何回報錯誤 |
| 讓它炸、典型死法、翻車、陰險 | 戲劇化，不能準確指出行為 | 直接說明終止、常見錯誤、難以察覺的型別或流程問題 |
| 這門課不要用、既有標頭幾乎沒寫 | 課程指令或未提供的教材前提 | 改成本頁的型別選擇與介面判斷 |
| 只有第一個 error 值得看、try 完全一樣快 | 過度保證 | 先修第一個錯再重編檢查其餘；執行成本依實作判斷 |
| 編譯器候選「活下來／決勝負」 | 不必要的競賽敘事 | 改為符合條件、排除、選擇版本 |

技術術語、正確數值、比較的用途與教學轉場保留；沒有為了降低口語密度而刪除表格、圖或重要說明。

整合技術判斷與修正，並核對每組複查回報。審查不以關鍵字沒有命中就判定通過。

| 範圍 | 發現與完成的修正 |
|---|---|

| P2 | 三元運算子先用純量例子，不提前要求 vector/range-for；修正 const 參考選擇規則與互動顏色說明。 |
| P3 | 統一參考語意與儲存空間說明；補 `<string>`；以回傳值先處理生命週期，速查不再提前放完整類別。 |
