正課九島授課順序 01–09

拱橋依授課順序串起九座島，可以自由進入任何一章。

  1. 01 C++ 導論 位址郵局 型別佔多少位元組、指標存的是位址，再用 Fraction 與邏輯閘電路走完類別、多載與繼承。 需要時可查閱：C++ 基礎與編譯流程、陣列、指標與動態記憶體、類別與物件
  2. 02 演算法分析 成長溫室 用大 O（Big-O）描述成長速度，比較 anagram 的四種解法，並看 vector 與 string 各操作的成本。 需要時可查閱：流程控制、vector 與 string、map、set 與迭代器
  3. 03 陣列與稀疏矩陣 連棟倉庫 連續格子與位址計算、二維陣列的列優先（row-major）配置、自己寫 ArrayList，以及稀疏矩陣的字典式表示法（Dictionary of Keys，DOK）。 需要時可查閱：陣列、指標與動態記憶體、vector 與 string、類別與物件
  4. 04 鏈結串列 散落小屋 節點散在記憶體各處，只靠指標相連。實作無序與有序串列，再學哨兵節點、雙向與環狀串列。 需要時可查閱：陣列、指標與動態記憶體、類別與物件、類別延伸與模板入門
  5. 05 堆疊、佇列與 Deque 碼頭三設施 限制「從哪裡進、從哪裡出」帶來的力量：括號配對、中序轉後序、印表機模擬與回文判斷。 需要時可查閱：vector 與 string、類別與物件、類別延伸與模板入門
  6. 06 遞迴 層疊塔 遞迴三法則與呼叫堆疊，河內塔、碎形與迷宮，最後用動態規劃解找零錢。 需要時可查閱：函式與參考、vector 與 string
  7. 07 搜尋與排序 郵務分揀所 循序與二分搜尋、雜湊表與碰撞處理，以及六種排序法的逐步動畫。 需要時可查閱：vector 與 string、map、set 與迭代器
  8. 08 圖與圖演算法 車站網 相鄰矩陣與相鄰串列、廣度優先搜尋（Breadth-First Search，BFS）與深度優先搜尋（Depth-First Search，DFS），再到 Dijkstra 最短路徑與 Prim 最小生成樹。 需要時可查閱：vector 與 string、map、set 與迭代器、類別與物件
  9. 09 樹與樹演算法 山頂纜車站 三種走訪、Binary Heap 與優先佇列、二元搜尋樹（Binary Search Tree，BST）的插入與刪除，到 AVL 旋轉。 需要時可查閱：陣列、指標與動態記憶體、類別與物件、類別延伸與模板入門

C++ 工坊島C++ 先備 · 查閱用

九間工坊，各教一種語法工具：讀正課卡住時，再進來查。

  1. P1 C++ 基礎與編譯流程 基礎工坊 從完整程式走過編譯四階段，拆解型別、輸入輸出與轉型，再練習讀懂錯誤訊息。
  2. P2 流程控制 流程工坊 追蹤短路求值、條件分支與各種迴圈，並計算巢狀迴圈的執行次數。
  3. P3 函式與參考 函式工坊 追蹤引數、回傳與作用域，分清傳值和傳參考，並理解遞迴的呼叫堆疊。
  4. P4 陣列、指標與動態記憶體 指標工坊 分清指標本身與目標物件，理解指標算術、堆疊與堆積，以及配置、釋放和所有權。
  5. P5 vector 與 string 容器工坊 容器增刪、容量與攤還、三種走訪、迭代器失效，以及文字處理和串接成本。
  6. P6 map、set 與迭代器 查詢工坊 從鍵值查詢走到迭代器、有序與無序容器，再完成計數、去重和分組。
  7. P7 檔案與例外 檔案工坊 處理路徑、讀寫模式與逐行解析，追蹤串流狀態，並讓例外跨函式傳遞。
  8. P8 類別與物件 類別工坊 把資料和操作包成類別：建構子、封裝與成員函式，是讀懂課程標頭的基礎。
  9. P9 類別延伸與模板入門 模板工坊 繼承與多型、抽象介面、運算子，以及看懂 template <typename T> 的容器寫法。
