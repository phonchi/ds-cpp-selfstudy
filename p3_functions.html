1. 函式把一項工作變成可重複使用的名字

運費計算可能在結帳、估價與訂單確認時都要做。把規則放進函式，只要呼叫同一個名字，就不必複製整段計算。

先認識四個部分

int shipping(int weight) {
    return weight * 5;
}

int 是回傳型別，表示結果為整數；shipping 是函式名稱；小括號內的 int weight 是參數；大括號內是函式本體。return 結束函式並交回結果。

完整可執行例子

#include <iostream>

int shipping(int weight) {
    return weight * 5;
}

int main() {
    int fee = shipping(3);
    std::cout << "運費：" << fee << "\n";
    return 0;
}
預期輸出
運費：15

執行到 shipping(3) 時，數值 3 交給參數 weight；函式算出 15 並回傳，接著 15 被存進 fee。

不回傳值的 void

#include <iostream>

void showConfirmation() {
    std::cout << "訂單已確認\n";
}

int main() {
    showConfirmation();
    return 0;
}
預期輸出
訂單已確認

void 表示這個函式只執行動作，不交回數值。呼叫時仍要寫小括號。

2. 作用域決定名稱在哪裡可用

函式的參數與函式本體內宣告的區域變數，只在該函式的大括號內可見。

#include <iostream>

int shipping(int weight) {
    int fee = weight * 5;
    return fee;
}

int main() {
    std::cout << fee << "\n";
    return 0;
}

fee 屬於 shipping 的作用域，main 看不到它。

呼叫前先讓編譯器看見宣告

#include <iostream>

int shipping(int weight);

int main() {
    std::cout << "運費：" << shipping(4) << "\n";
    return 0;
}

int shipping(int weight) {
    return weight * 5;
}
預期輸出
運費：20

上方的 int shipping(int weight); 是函式宣告，分號不可少。它先說明呼叫方式，完整定義可以放在後面。

3. 傳值：參數是獨立副本

語法

void addPoints(int points) {
    points = points + 10;
}

參數寫成一般的 int，呼叫時會複製數值。函式改的是 points 副本。

#include <iostream>

void addPoints(int points) {
    points = points + 10;
    std::cout << "函式內：" << points << "\n";
}

int main() {
    int score = 20;
    addPoints(score);
    std::cout << "呼叫後：" << score << "\n";
    return 0;
}
預期輸出
函式內：30
呼叫後：20

4. 先單獨理解參考：同一個變數的別名

語法

int value = 20;
int &alias = value;

int& 表示整數參考。alias 不是新副本，而是 value 的另一個名字；宣告時必須綁定。

#include <iostream>

int main() {
    int value = 20;
    int &alias = value;
    alias = alias + 5;
    std::cout << value << " " << alias << "\n";
    return 0;
}
預期輸出
25 25

參考參數：讓函式改到呼叫端變數

#include <iostream>

void addPoints(int &points) {
    points = points + 10;
}

int main() {
    int score = 20;
    addPoints(score);
    std::cout << "呼叫後：" << score << "\n";
    return 0;
}
預期輸出
呼叫後：30

points 綁定到 score；透過任何一個名稱修改，改到的都是同一個整數。

const int&：唯讀別名

#include <iostream>

void showPoints(const int &points) {
    std::cout << "點數：" << points << "\n";
}

int main() {
    int score = 30;
    showPoints(score);
    return 0;
}
預期輸出
點數：30

const 禁止函式透過參考修改原值，清楚表達「只讀」。

互動：傳值與傳參考逐步比較

呼叫前：score = 20
建立參數 points
執行 points = points + 10
函式結束，觀察 score

模式：傳值；尚未開始

5. 同名函式與省略引數

多載：參數不同，可以共用名稱

#include <iostream>

int shipping(int weight) {
    return weight * 5;
}

double shipping(double weight) {
    return weight * 5.0;
}

int main() {
    std::cout << shipping(3) << " " << shipping(3.5) << "\n";
    return 0;
}
預期輸出
15 17.5

編譯器依引數型別選擇版本；不能只靠回傳型別區分。

預設引數：省略時使用預設值

#include <iostream>

int shipping(int weight, int rate = 5) {
    return weight * rate;
}

int main() {
    std::cout << shipping(4) << " " << shipping(4, 7) << "\n";
    return 0;
}
預期輸出
20 28

第一個呼叫省略 rate，所以使用 5；有預設值的參數要排在參數列後方。

動手預測

若 score 初值是 8，分別交給傳值與參考版本的 addPoints，呼叫後各是多少？

提示與答案

傳值只改副本，仍是 8；參考參數是別名，因此變成 18。

P3 速查

T f(T x) 以值傳入副本；void f(T& x) 可修改呼叫端；const T& 是唯讀別名。宣告以分號結尾，定義包含函式本體。
