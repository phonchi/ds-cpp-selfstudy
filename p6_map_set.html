PART 01

鍵值與唯一集合的資料模型

當資料的核心問題是「用鍵找值」或「某個值是否出現過」，map/set 比在 vector 中逐項掃描更直接。map<K,V> 把唯一鍵 K 對應到值 V；set<K> 只保存唯一鍵。

容器保存內容例子
map<string,int>鍵與值品名 → 庫存
set<string>唯一鍵已使用的帳號
unordered_map<K,V>鍵值、無排序保證大量快速查表
unordered_set<K>唯一鍵、無排序保證大量 membership 檢查
#include <iostream>
#include <map>
#include <set>
#include <string>
using namespace std;
int main() {
    map<string,int> stock{{"tea",3},{"rice",8}};
    set<string> tags{"sale","new","sale"};
    cout << stock["tea"] << '\n';
    cout << tags.size() << '\n';
}
預期輸出
3
2

map 的每個鍵只出現一次；set 也只保留唯一鍵，因此重複的 sale 被去除。尖括號依序指定鍵與值的型別。

動手練習

要保存「學號 → 姓名」與「已報到學號」，各用什麼型別？

看解答與理由

前者用 map<string,string>，後者用 set<string>。

PART 02

map iterator、pair 與箭頭

P5 已把 iterator 定義成容器位置。map 的 iterator 指向一筆「鍵和值的配對」。*it 取得整個 pair；pair 有 first 與 second 成員，所以 (*it).first 是鍵、(*it).second 是值。

箭頭只是縮寫，不需要先學自己寫 class

it->first 完全等價於 (*it).first；箭頭表示「先對 it 解參考，再用點號取成員」。這裡只需知道標準庫 pair 已有 first/second；自己定義 class 到 P8 再學。map 的鍵視為唯讀，不能透過 iterator 改 first，否則會破壞排序／雜湊位置；second 可以改。

#include <iostream>
#include <map>
#include <string>
using namespace std;
int main() {
    map<string,int> price{{"apple",30},{"bread",45}};
    for (auto it=price.begin(); it!=price.end(); ++it) {
        it->second += 5;
        cout << (*it).first << ':' << it->second << ' ';
    }
    cout << '\n';
}
預期輸出
apple:35 bread:50

begin 指排序後第一筆，end 是尾後哨兵，區間仍是 [begin,end)。每輪先把值加 5，再印鍵和值。map 依鍵排序，所以 apple 先於 bread。

動手練習

把 it->second 不用箭頭改寫。

看解答與理由

(*it).second。括號必要，確保先解參考再取成員。

PART 03

[] 的副作用與 count、find、at

m[k] 看起來像查詢，其實在鍵不存在時會插入 k，並把值做 value initialization：int 得 0、string 得空字串、vector 得空容器。這使計數很方便，也會讓純查詢意外改動資料。

需求寫法找不到時
要寫入／計數m[k]插入預設值
只問是否存在m.count(k)回 0，不插入
找位置並使用m.find(k)回 end，不插入
必須存在才取值m.at(k)丟 out_of_range，不插入
#include <iostream>
#include <map>
#include <string>
using namespace std;
int main() {
    map<string,int> stock{{"tea",3}};
    cout << stock["coffee"] << " " << stock.size() << '\n';
    cout << stock.count("juice") << " " << stock.size() << '\n';
    auto it=stock.find("tea");
    if (it != stock.end()) cout << it->second << '\n';
}
預期輸出
0 2
0 2
3

第一個 [] 建立 coffee→0，所以 size 變 2；count 只回 0，size 不變。find 找到 tea 後才讀值。若只是檢查存在，別寫 if (m[k])：它既插入，又把「存在但值為 0」誤判為不存在。

cout << stock.at("juice"); // 錯誤示例：丟 out_of_range；完整捕捉方式見 P7
界線

at 的報錯模式與 vector::at 相同概念：以例外回報鍵不存在。P7 才完整教 try/catch，本頁不執行這段錯誤片段。

動手練習

庫存可以合法等於 0，如何判斷 tea 這個鍵存在？

看解答與理由

用 stock.count("tea") != 0 或 stock.find("tea") != stock.end()，不要把值當存在性。

PART 04

從 auto [k,v] 到 structured bindings

C++17 的 structured binding 可以把 pair 拆成有名字的兩部分。先看單筆：auto [k,v] = *m.begin(); 建立 k、v 兩個複製值。放入範圍 for 時，for (const auto& [k,v] : m) 逐筆以唯讀參考綁定，避免複製。

#include <iostream>
#include <map>
#include <string>
using namespace std;
int main() {
    map<string,int> cups{{"Amy",2},{"Bo",1}};
    auto [firstName, firstCups] = *cups.begin();
    cout << firstName << '=' << firstCups << '\n';
    for (auto& [name,count] : cups) count += 1;
    for (const auto& [name,count] : cups) cout << name << ':' << count << ' ';
    cout << '\n';
}
預期輸出
Amy=2
Amy:3 Bo:2

第一個 auto [..] 是複製，不會連動原 map。第一個範圍 for 使用 auto&，因此 count 代表真實 second，可以修改；第二個使用 const auto&，適合只讀。鍵 name 仍不能修改。

反例

for (auto [k,v] : m) ++v; 只改每筆複製品，map 不變。要改值用 auto& [k,v]。

動手練習

只讀輸出 map，兼顧不複製與不可誤改，迴圈標頭怎麼寫？

看解答與理由

for (const auto& [key,value] : m)。

PART 05

ordered 與 unordered：需求、順序、成本

map/set 是 ordered 容器，依比較規則排序，查詢、插入、刪除保證 O(log n)。unordered_map/unordered_set 用雜湊，平均 O(1)，最壞可到 O(n)，且走訪順序沒有保證。選擇取決於需求，不是永遠選平均最快者。

需求選擇理由
需要排序輸出／最小鍵／lower_boundmap 或 set鍵保持順序，操作 O(log n)
只需快速查存在／鍵找值unordered 版本平均 O(1)，順序不保證
需要最壞情況 O(log n) 保證map 或 set樹的界線穩定
鍵沒有可用 hashmap/set 或自訂 hashunordered 需要雜湊規則
#include <iostream>
#include <map>
#include <string>
using namespace std;
int main() {
    map<string,int> due{{"Wed",3},{"Mon",1},{"Tue",2}};
    for (const auto& [day,n] : due) cout << day << ':' << n << ' ';
    cout << '\n';
}
預期輸出
Mon:1 Tue:2 Wed:3

這個例子刻意需要有序輸出，因此用 map。若換 unordered_map，三筆都會保存，但輸出順序不可寫入測試期待，也不應觀察某次結果後當作規則。

動手練習

一百萬個識別碼只做「是否出現」，不需順序，預設選什麼？限制是？

看解答與理由

預設 unordered_set，平均 O(1)；限制是走訪順序不保證、最壞可退化 O(n)，且鍵需可雜湊。

PART 06

find、半開區間與安全 erase

find 回傳 iterator；找到才能解參考。erase 有三種常見形式：erase(key) 回傳刪除筆數；erase(it) 在 C++11 起回傳下一個 iterator；erase(first,last) 刪左閉右開區間。

#include <iostream>
#include <map>
using namespace std;
int main() {
    map<int,int> score{{1,40},{2,75},{3,50},{4,90}};
    for (auto it=score.begin(); it!=score.end(); ) {
        if (it->second < 60) it=score.erase(it);
        else ++it;
    }
    for (const auto& [id,s] : score) cout << id << ':' << s << ' ';
    cout << '\n';
}
預期輸出
2:75 4:90

刪除目前節點只讓指向被刪元素的 iterator 失效；其他 map/set iterator 仍有效。這與 vector erase 使後段位置失效不同，但安全迴圈同樣採用回傳值。不要在 range-for 中直接刪當前元素，因為迴圈內部仍要推進自己的 iterator。

互動：依值篩掉 map 項目

追蹤 iterator 與容器；不會解參考 end。

for (auto it=m.begin(); it!=m.end(); ) {
  if (it->second < 60) it=m.erase(it);
  else ++it;
}


反例
find 失敗時 it==end；it->second 沒有有效物件可讀。比較 end 是合法的，解參考 end 才錯。


動手練習
刪除鍵 "draft" 並知道是否真的刪到，怎麼寫？
看解答與理由
size_t removed = m.erase("draft");；map 鍵唯一，所以 removed 是 0 或 1。





PART 07
完整應用一：頻率計數


計數是 map 最短也最實用的模式。因為不存在鍵的 freq[word] 先建立 0，接著 ++ 就得到 1；再次遇到則累加同一筆。


#include <iostream>
#include <map>
#include <string>
#include <vector>
using namespace std;
int main() {
    vector<string> words{"pear","apple","pear","tea","apple","pear"};
    map<string,int> freq;
    for (const string& word : words) ++freq[word];
    for (const auto& [word,n] : freq) cout << word << ':' << n << ' ';
    cout << '\n';
}
預期輸出
apple:2 pear:3 tea:1 



第一次 pear 建 0 再加成 1，之後加到 3。選 map 是因為最後希望按單字排序；若只查頻率且不要求順序，可用 unordered_map，計數程式本身不變。


互動：[] 如何完成計數
每一 frame 是處理一個單字後的真實 map 狀態。
for (const string& word : words) {
  ++freq[word];
}


動手練習
若輸出要保持第一次出現順序，只換 unordered_map 就可以嗎？
看解答與理由
不可以，unordered 也不保證插入順序。可另用 vector 記第一次出現的鍵，用 set/map 判斷與計數。





PART 08
完整應用二：去重與順序


set 的 insert 自動忽略重複鍵，適合去重與 membership。若只需要不同項目且要排序結果，直接用 set；若要保留原始第一次出現順序，需要一個 seen set 加一個 output vector。


#include <iostream>
#include <set>
#include <string>
#include <vector>
using namespace std;
int main() {
    vector<string> input{"red","blue","red","green","blue"};
    set<string> seen;
    vector<string> unique;
    for (const string& x : input)
        if (seen.insert(x).second) unique.push_back(x);
    for (const string& x : unique) cout << x << ' ';
    cout << '\n';
}
預期輸出
red blue green 



insert 回傳 pair：first 是 iterator，second 是 bool，表示這次是否真的插入。只有第一次看到 x 時 second 為 true，才把它加入 unique，所以輸出保留第一次出現順序。


界線
只寫 set<string> s(input.begin(),input.end()) 會得到排序後的唯一集合，無法保留第一次出現順序。需求不同，答案不同。


動手練習
只需排序後去重，怎麼簡化？
看解答與理由
set<string> unique(input.begin(), input.end());，再走訪 set。這使用 [begin,end) 範圍建構。





PART 09
完整應用三：一對多分組


分組把同一鍵的多個值聚在一起，型別常是 map<K,vector<V>>。[] 找不到鍵時建立空 vector，接著 push_back；這次副作用正是我們要的。


#include <iostream>
#include <map>
#include <string>
#include <vector>
using namespace std;
int main() {
    vector<pair<string,string>> records{{"fruit","pear"},{"drink","tea"},{"fruit","apple"}};
    map<string,vector<string>> groups;
    for (const auto& [category,item] : records) groups[category].push_back(item);
    for (const auto& [category,items] : groups) {
        cout << category << ':';
        for (const string& item : items) cout << ' ' << item;
        cout << '\n';
    }
}
預期輸出
drink: tea
fruit: pear apple



第一次遇到 fruit 時，groups[fruit] 建立空 vector，再加入 pear；第二次沿用同一個 vector 加 apple。外層 map 讓分類按鍵排序，內層 vector 保留各分類的輸入順序。


反例
若只想查看某分類，groups[missing] 會建立空分類。唯讀查看應先 find，找到才讀 it->second。


動手練習
要保存「課程 → 多位學生」，且課程排序、學生保留加入順序，型別？
看解答與理由
map<string, vector<string>>。外層 map 排課程，內層 vector 留加入順序。

語法速查與選擇檢核


目的首選關鍵界線
寫入或累加m[k]不存在時會插入
唯讀存在判斷countmap/set 結果 0 或 1
找到後取資料find先比較 end
邊走邊刪it=erase(it)不使用舊 iterator
要排序／範圍查詢orderedO(log n) 保證
只求平均快速查表unordered平均 O(1)，無順序保證


延伸查閱：std::map、std::set、std::unordered_map。


動手練習
一句話區分 []、find 與 at。
看解答與理由
[] 可讀寫且缺鍵會插入；find 尋找位置而不插入資料、缺鍵回 end；at 要求鍵存在、缺鍵丟 out_of_range。
