PART 01

最小 class 與物件

class 把資料與操作寫在同一個型別中；定義結尾的分號不可省略。public: 是存取區段標籤，表示後面的成員可由類別外使用。Counter 是自訂型別名稱，Counter c; 建立名叫 c 的物件。value 是保存數值的資料成員；increment() 是操作資料的成員函式，沿用 P3 的函式語法。物件用 . 存取公開成員：讀資料寫 c.value，呼叫函式寫 c.increment()。

#include <iostream>
class Counter {
  public:
  int value=0;
  void increment(){
    value++;
  }
};
int main(){
  Counter c;
  c.increment();
  std::cout<<c.value<<'\n';
}
預期輸出
1

練習：再呼叫兩次 increment()，預測輸出。

PART 02

public、private 與建構式

class 若未寫存取區段，預設就是 private。public: 後面放外部可呼叫的操作；private: 後面放內部狀態。建構式與類別同名、沒有回傳型別，建立物件時自動執行。Counter(int start) : value(start) 的冒號部分是初始化串列：它在進入大括號前直接建立 value，而不是先建立再賦值。

#include <iostream>
class Counter {
  int value;
  public:
  Counter(int start):value(start){
  }
  void increment(){
    value++;
  }
  int get() const{
    return value;
  }
};
int main(){
  Counter c(2);
  c.increment();
  std::cout<<c.get()<<'\n';
}
預期輸出
3

get() const 的 const 寫在參數括號後，承諾這個成員函式不改物件。練習：嘗試從 main 直接讀 c.value，解釋編譯錯誤。

PART 03

this 與物件指標

this 指向目前物件。先用不同名字完成建構式 Counter(int start) : value(start)；到了 set，再刻意讓參數也叫 value，使用 this->value = value 區分「成員」與「參數」。物件指標用 ->，等同先解參考再用點號。

#include <iostream>
class Counter{
  int value;
  public:
  Counter(int value):value(value){
  }
  void increment() {
    value++;
  }
  void set(int value){
    this->value=value;
  }
  int get()const{
    return value;
  }
};
int main(){
  Counter c(1);
  Counter* p=&c;
  p->set(7);
  std::cout<<p->get()<<'\n';
}
預期輸出
7

練習：把最後一行改用物件 c 與點號。

PART 05

解構式

解構式寫成 ~類別名()，物件生命結束時自動呼叫，常用來做收尾。這個 Counter 沒有擁有動態記憶體，只示範呼叫時機。

#include <iostream>
#include <string>
class Counter{
  std::string name;
  public:
  Counter(std::string n):name(n){
    std::cout<<"建立 "<<name<<'\n';
  }
  ~Counter(){
    std::cout<<"結束 "<<name<<'\n';
  }
};
int main(){
  Counter c("A");
  std::cout<<"使用 A\n";
}
預期輸出
建立 A
使用 A
結束 A

練習：在內層大括號建立物件，觀察離開大括號時的輸出。

語法速查

語法用途
class Counter { ... };定義自訂型別，最後的分號不可省略。
public: / private:區分外部可用的介面與內部資料。class 預設為 private。
Counter c; / c.increment();建立物件，再呼叫它的成員函式。
Counter(int start) : value(start) {}建構式以初始化串列設定成員初值。
int get() const { return value; }括號後的 const 表示不透過此函式修改物件。
this->value / p->get()this 指向目前物件；物件指標以 -> 存取成員。
~Counter() { ... }物件生命結束時自動執行的解構式。
