## 修正內容

- P1 的 `#errors` 補三類錯誤對照、語意一詞的使用範圍、邏輯錯誤的完整對照程式、整數除零與陣列越界的事前檢查程式。保留原有語法、型別、未宣告名稱及連結錯誤的範例。
- P1 的自訂標頭範例逐項解釋 `#pragma once`、`inline`、函式與回傳型別，並連到 P8 的標準 include guard 說明；補 `boolalpha`、輸出精度及 `NDEBUG`。
- 導論不再把所有執行期錯誤稱為例外。修正有號溢位測驗、空指標互動說明及越界反例的固定輸出。C++17 的 UB 不保證當機、不保證繞回，也不會自動變成 C++ 例外。
- P2–P9 補首次使用的函式、迭代器、初始化串列、雜湊、RAII、標頭防護、刪除函式及虛擬函式說明；修正參考儲存、非 virtual 同名遮蔽與覆寫的混淆。
- 正課補 DOK、`size_t`、轉型與指標參考等範例讀法；陣列攤平改用真正的一維陣列，避免用指標跨越二維陣列的子陣列邊界。兩個對應的 enrich 模板同步修正，未重跑一次性產生器。
- 清除實際簡體殘留 `读`、`较`；OpenCC 僅用來列出候選，逐項排除「划算」「不准」「干擾」「上游」等合法用字，未機械轉換全文。
- P1 新增三張中英字卡與三題四選一，既有題卡亦核對相同概念，未刪除原有題卡。
- 實際瀏覽器檢查發現正課共用網格的自動最小寬度、未包覆表格、河內塔畫布與圖頁速度滑桿造成手機橫向溢出；已讓網格子項可縮小、寬內容在可捲動區塊內保留完整內容。
