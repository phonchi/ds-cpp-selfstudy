PART 01

從清單需求到 vector<T>

程式常要保存「數量到執行時才知道」的一串同型別資料，例如購物清單、每小時溫度或文字的每個字元。原生陣列的長度固定；vector 會自己記住元素數量，也能在執行中增減。string 則把字元序列包成文字專用型別。

先讀懂物件、點號與樣板參數

vector<int> scores; 中，vector 是容器種類，角括號的 int 指定每一格能放的元素型別，scores 才是變數名稱。換成 vector<string>，語法不變，但每格改放一個 string。

容器是一個物件；點號表示「請這個物件做事」。因此 scores.size() 是請 scores 回報項目數，scores.push_back(80) 是請 scores 在尾端放入 80。括號表示呼叫方法；即使沒有引數，size() 的括號也不能省。

寫法逐項讀法用途
vector<int> scores;int 是元素型別；scores 是物件可增減的整數清單
scores.push_back(80);對 scores 呼叫 push_back，傳入 80尾端加入
scores.size()對 scores 呼叫 size，不傳引數取得目前項目數
#include <iostream>
#include <string>
#include <vector>
using namespace std;
int main() {
    vector<string> errands;
    errands.push_back("買牛奶");
    errands.push_back("寄包裹");
    cout << errands.size() << " 件：" << errands[0] << "、" << errands[1] << "\n";
}
預期輸出
2 件：買牛奶、寄包裹

第 6 行建立空容器；第 7、8 行依序加入兩個字串，因此有效索引是 0 與 1。第 9 行的 size() 回傳 2。方括號不是第幾個人的日常編號，而是從 0 開始的位移。

界線

vector<int> 只能直接放 int；它不是「任何東西都可放」的袋子。需要不同型別時，應重新設計資料型別，而不是期待 vector 自動改型。

動手練習

把上例改成三項待辦並印出最後一項；索引要怎麼寫？

看解答與理由

加入 errands.push_back("繳水費");，最後一項是 errands[errands.size()-1]。只有在非空時才能減 1。

PART 02

初始化、索引與界線檢查

四種初始化各回答不同問題

初始化發生在物件誕生的那一刻。空建構適合邊讀邊加；計數建構適合已知格數；清單初始化適合已知內容；複製建構適合保留快照。

語法結果何時用
vector<int> a;空，size 為 0稍後 push_back
vector<int> b(4, 7);四個 7已知格數與初值
vector<int> c{4, 7};兩項：4、7列出實際元素
vector<int> d(c);複製 c；之後各自修改保留獨立副本

括號與大括號不能隨意交換：vector<int> x(4, 7) 呼叫「數量、初值」建構式；vector<int> y{4, 7} 優先解讀為元素清單。前者四格，後者兩格。

#include <iostream>
#include <vector>
using namespace std;
int main() {
    vector<int> repeated(4, 7);
    vector<int> listed{4, 7};
    vector<int> copied(listed);
    copied[0] = 99;
    cout << repeated.size() << " " << repeated[0] << "\n";
    cout << listed.size() << " " << listed[0] << "\n";
    cout << copied.size() << " " << copied[0] << "\n";
}
預期輸出
4 7
2 4
2 99

第 5 行建立四個 7；第 6 行只列出兩項。第 7 行複製出新容器，第 8 行改 copied 不會改 listed，因為 vector 的一般複製是整份元素複製。

索引與 at

v[i] 快而且不檢查界線；若 i 不合法，行為未定義。v.at(i) 會檢查並丟出 out_of_range。初學除錯時，索引來自輸入或計算便可優先用 at。完整捕捉例外的語法在 P7；本頁先理解錯誤模式，不塞入尚未教過的 try/catch。

vector<int> v{10, 20, 30};
cout << v.at(5); // 錯誤示例：執行時丟出 out_of_range；這是片段，不要執行
反例

不要用 v[v.size()] 取最後一項；size 是尾後位置。非空 vector 的最後一項是 v[v.size()-1] 或 v.back()。

動手練習

預測 vector<int> x(3, 5); vector<int> y{3, 5}; 的內容。

看解答與理由

x 是 {5,5,5}，y 是 {3,5}。括號選計數建構式，大括號列元素。

PART 03

三種走訪與 iterator 基礎

「走訪」是依序看每個元素。三種寫法各有用途：需要索引用傳統 for；只關心值用範圍 for；要傳給 STL、表示位置或區間時用 iterator。

寫法適合情境易錯點
for (size_t i=0; i<v.size(); ++i)同時需要 i條件必須是 <
for (const auto& x : v)只讀每個元素省略 & 會複製
for (auto it=v.begin(); it!=v.end(); ++it)操作位置／區間end 不可解參考
#include <iostream>
#include <vector>
using namespace std;
int main() {
    vector<int> v{4, 7, 9};
    for (size_t i=0; i<v.size(); ++i) cout << i << ':' << v[i] << ' ';
    cout << '\n';
    for (const int& x : v) cout << x*2 << ' ';
    cout << '\n';
    for (vector<int>::iterator it=v.begin(); it!=v.end(); ++it) *it += 1;
    for (int x : v) cout << x << ' ';
    cout << '\n';
}
預期輸出
0:4 1:7 2:9 
8 14 18 
5 8 10

auto 請編譯器從右側運算式推導型別：auto it=v.begin() 的 it 就是該 vector 的 iterator。它不代表「任意型別」；型別在編譯時已固定。範圍 for 的 auto x 同樣會推得元素型別，但 x 仍是每輪的複製值；寫 auto& x 才是元素別名。

begin() 指第一項；end() 指最後一項的再下一格，形成左閉右開區間 [begin,end)。*it 取得目前元素，++it 前進。空容器的 begin 等於 end，所以迴圈自然跑零次。

反例

*v.end() 永遠不合法。end 是停下來比較用的哨兵，不是一個元素。範圍 for 若寫 auto x，x 是複製品；要修改原元素寫 auto& x。

動手練習

要把全部元素加 10，範圍 for 怎麼寫？

看解答與理由

for (int& x : v) x += 10;。& 讓 x 直接代表容器中的元素。

PART 04

五種增刪與搬移成本

清單會成長也會縮短。尾端操作通常便宜；在中間插入或刪除，後面的元素必須搬動來騰空或補洞。先把語法和成本一起記，才能在資料變大時預測慢在哪裡。

操作效果典型成本
push_back(x)尾端加入 x攤還 O(1)
pop_back()移除尾端；不回傳該值O(1)
insert(begin()+i,x)在索引 i 前插入O(n)，搬動 i 之後元素
erase(begin()+i)刪除索引 iO(n)，補洞
clear()刪除全部元素O(n)，逐一銷毀元素
#include <iostream>
#include <vector>
using namespace std;
void show(const vector<int>& v) { for (int x : v) cout << x << ' '; cout << '\n'; }
int main() {
    vector<int> stops{10, 30};
    stops.push_back(40);             // 10 30 40
    stops.insert(stops.begin()+1,20);// 10 20 30 40
    stops.erase(stops.begin()+2);    // 10 20 40
    stops.pop_back();                // 10 20
    show(stops);
    stops.clear();
    cout << stops.size() << '\n';
}
預期輸出
10 20 
0

insert 的位置是「新元素要放在誰前面」；begin()+1 指索引 1，所以 20 插在原本 30 前。erase 刪掉該位置後，右邊元素左移。pop_back 只移除，若需要舊尾值，要先讀 back() 再 pop。

成本界線

O(n) 不是說每次一定很慢，而是資料量加倍時，中間搬移量可能也加倍。偶爾編輯短清單沒有問題；若大量在前端增刪，後面介紹的 deque 或專門資料結構更合適。

動手練習

把 {2,4,6} 變成 {2,3,4}，寫出兩個操作並說明搬動。

看解答與理由

先 v.insert(v.begin()+1,3)，再 v.pop_back()。insert 會把 4、6 往右搬；pop_back 不必搬其他元素。

PART 05

size、capacity、reserve 與攤還

size() 是已存在的元素數，capacity() 是目前已配置、尚未重新配置便能容納的元素數。必有 size ≤ capacity，但兩者不必相等。

為什麼 push_back 平均仍快

空位尚足時，只在尾端建一個元素。空位不足時，vector 會另找更大的連續區塊，把所有元素搬過去，再釋放舊區塊；那一次是 O(n)。實作通常按倍數成長，因此昂貴搬家不會每次發生，分攤到許多次 push_back 後稱為「攤還 O(1)」。成長倍數與實際 capacity 數列不是 C++ 標準保證，不能把「一定雙倍」寫進程式邏輯。

reserve(n) 至少預留 n 格容量，但不建立元素，size 不變。若已大致知道會讀入幾筆，可先 reserve 減少重配置。resize(n) 才會改元素數；兩者不要混淆。

#include <iostream>
#include <vector>
using namespace std;
int main() {
    vector<int> samples;
    samples.reserve(3);
    cout << samples.size() << " " << (samples.capacity() >= 3) << "\n";
    for (int x : {8, 5, 9}) samples.push_back(x);
    cout << samples.size() << " " << samples[2] << "\n";
}
預期輸出
0 1
3 9

輸出只檢查標準保證：reserve(3) 後 capacity 至少為 3，所以印布林值 1；沒有假定容量恰為 3。三次加入後 size 是 3。

互動：分辨 size、capacity 與搬家

這是概念模型；容量用「至少」描述，避免假定特定 STL 的成長倍數。

vector<int> v;
v.reserve(2);
v.push_back(8);
v.push_back(5);
v.push_back(9);


動手練習
已知會讀 10,000 筆，應用 reserve 還是 resize？
看解答與理由
若只是想避免多次搬家，用 v.reserve(10000)，size 仍為 0，再 push_back。若 10,000 個元素此刻就要存在，才用 resize。





PART 06
iterator 失效與安全 erase


iterator 與指向元素的指標都依賴容器目前的儲存位置。vector 重配置時全部元素搬家，先前所有 iterator、指標與參考都失效。erase(pos) 則讓 pos 與其後位置失效，因為後方元素向左搬。


安全規則：不要執行失效 iterator


失效後再解參考是未定義行為：可能看似成功，也可能印垃圾或當掉。正確作法是使用操作回傳的新 iterator，或在可能重配置後重新取得 begin。


#include <iostream>
#include <vector>
using namespace std;
int main() {
    vector<int> v{10, 20, 30, 40};
    for (auto it=v.begin(); it!=v.end(); ) {
        if (*it % 20 == 0) it = v.erase(it);
        else ++it;
    }
    for (int x : v) cout << x << ' ';
    cout << '\n';
}
預期輸出
10 30 



erase 回傳「被刪元素後面的新位置」。刪 20 後，新 iterator 指 30，不額外 ++；保留 10 或 30 時才 ++。這避免跳過元素，也沒有碰失效位置。


auto it = v.begin();
v.push_back(99);
cout << *it; // 錯誤示例：push_back 若重配置，it 已失效；不要執行


互動：erase 時 iterator 指向哪裡
逐格看安全刪除；紅色警戒以文字呈現，不會執行失效 iterator。
for (auto it=v.begin(); it!=v.end(); ) {
  if (*it % 20 == 0) it=v.erase(it);
  else ++it;
}


動手練習
為何不能寫 erase(it); ++it;？
看解答與理由
erase 後舊 it 已失效，對它 ++ 仍是使用失效 iterator。應寫 it = v.erase(it)。





PART 07
二維 vector：表格與不規則列


vector<vector<int>> 是「外層每一格又是一個 vector」。常用來存表格、棋盤或每位學生的一串成績。先讀外層索引 row，再讀內層索引 col：grid[row][col]。


#include <iostream>
#include <vector>
using namespace std;
int main() {
    vector<vector<int>> seats{{1,0,1},{0,1,1}};
    int occupied=0;
    for (size_t r=0; r<seats.size(); ++r)
        for (size_t c=0; c<seats[r].size(); ++c)
            occupied += seats[r][c];
    cout << seats.size() << " rows, " << occupied << " occupied\n";
}
預期輸出
2 rows, 4 occupied



外層 size 是列數；每一列可以有不同長度，所以內層條件必須用 seats[r].size()。若資料保證矩形才可拿第一列寬度套全部列，而且還要先確認不為空。


界線
二維 vector 不自動保證矩形。{{1,2},{3}} 完全合法；此時讀 v[1][1] 越界。


動手練習
建立 3×4、全為 0 的表格。
看解答與理由
vector<vector<int>> grid(3, vector<int>(4,0));。外層建立 3 列，每列由內層建構式建立 4 個 0。





PART 08
stack、queue、deque 的生活模型


有時需求只允許從特定端操作。stack 像復原紀錄：最後做的先撤銷。queue 像排隊：先來先服務。deque 是雙端佇列，兩端都能常數時間增刪，也是 stack/queue 常見的底層容器。


容器加入／查看／移除典型用途
stack<T>push / top / pop編輯器 undo、括號配對
queue<T>push / front / pop客服排隊、工作佇列
deque<T>push_front/back、front/back、pop_front/back兩端都有新資料


#include <iostream>
#include <queue>
#include <stack>
#include <string>
using namespace std;
int main() {
    stack<string> undo;
    undo.push("輸入 A"); undo.push("刪除 B");
    cout << "撤銷：" << undo.top() << '\n'; undo.pop();
    queue<string> line;
    line.push("小安"); line.push("小美");
    cout << "服務：" << line.front() << '\n'; line.pop();
    cout << "下一位：" << line.front() << '\n';
}
預期輸出
撤銷：刪除 B
服務：小安
下一位：小美



top/front 只查看，不移除；pop 只移除，不回傳。因此常見順序是先讀，再 pop。空容器呼叫 top/front/pop 沒有有效元素可用，先以 empty() 判斷。


範圍
這裡只建立使用者模型，不展開 stack/queue 的底層演算法。之後章節遇到 DFS/BFS 時，會直接使用這組介面。


動手練習
印出並移除 stack 頂端，且避免空容器錯誤。
看解答與理由
if (!s.empty()) { cout << s.top(); s.pop(); }。查看與移除是兩個動作。





PART 09
string、字元陣列、npos 與 substr


string 管理一串 char，會自己記長度並提供搜尋、切片、串接。C 風格字元陣列以 \0 結尾，容量與有效文字長度要由程式設計者小心處理；初學一般文字優先用 string。需要傳給舊式 C API 時，可用 s.c_str() 取得唯讀的結尾字元陣列指標。


需求string 寫法說明
長度s.size()char 數量；不含結尾字元
索引s[i] / s.at(i)一個 char
串接s += suffix修改 s
搜尋s.find(needle)位置或 string::npos
切片s.substr(pos,count)從 pos 起最多 count 個 char


#include <iostream>
#include <string>
using namespace std;
int main() {
    string code="AB-204";
    size_t dash=code.find('-');
    if (dash != string::npos) {
        string group=code.substr(0,dash);
        string number=code.substr(dash+1);
        cout << group << " / " << number << '\n';
    }
}
預期輸出
AB / 204



find 成功回傳第一個符合位置；失敗回傳特殊值 string::npos，不能用 -1 當跨平台契約。第一個 substr 取 [0,dash)，第二個省略 count，表示一路取到結尾。


UTF-8 的 byte 界線


string 的 size、索引、find 位置與 substr count 都以 char 單位運作；在常見 UTF-8 環境，一個中文字通常由多個 byte 組成。因此 substr(0,1) 可能切壞中文字。要按「可見字」處理，需要額外的 Unicode 函式庫或明確的編碼層，本頁不假裝 string 已懂 Unicode。


動手練習
若找不到連字號，為何不能直接 substr(dash+1)？
看解答與理由
dash 是 npos；加一可能回繞，且程式語意已不成立。先判斷 dash != string::npos。





PART 10
混合輸入與字串串接成本


cin >> value 以空白分隔 token，讀完整行則用 getline(cin,text)。混用時，>> 通常把換行留在輸入緩衝區，下一個 getline 會立刻讀到空行。getline(cin >> ws, text) 先用 ws 吃掉前導空白與換行，再讀一整行。


範例輸入
2026
C++ 入門筆記

#include <iostream>
#include <string>
using namespace std;
int main() {
    int year;
    string title;
    cin >> year;
    getline(cin >> ws, title);
    cout << '[' << year << "] " << title << '\n';
}
預期輸出
[2026] C++ 入門筆記



先讀整數 2026；ws 消耗其後換行，再由 getline 保留標題中的空白。代價是 ws 也會丟掉使用者刻意放在行首的空白；若那些空白有意義，改用一次 getline 讀原始行再自行解析。


串接的成本


a+b 建立新字串結果，反覆在迴圈寫 s = s + piece 可能一次次配置與複製愈來愈長的前綴，總成本可能接近平方級。要累積內容，優先 s += piece 或 s.append(piece)，已知大約長度可先 s.reserve(total)。一次性的短字串串接則不必過度優化。


string out;
for (const string& p : parts) out = out + p; // 反例：每輪可能複製整個舊 out
// 改為 out += p；若可估總長度，再先 reserve


動手練習
何時 getline(cin >> ws,s) 不是正確選擇？
看解答與理由
當行首空白是資料的一部分時。ws 會跳過所有前導空白，這時應保留原始行並明確處理前一個換行。





PART 11
語法速查與章末整合


想做的事首選語法先檢查
尾端加入v.push_back(x)可能重配置並使 iterator 失效
