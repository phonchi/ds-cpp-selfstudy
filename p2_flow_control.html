1. 比較先產生 bool

先讀語法

bool 名稱 = 比較運算式;

== != < <= > >= 比較兩個值，結果只有 true 或 false。相等比較是兩個等號；單一 = 是指定值。

#include <iostream>
int main() {
    int age = 20;
    bool adult = age >= 18;
    std::cout << adult << " " << (age == 17) << "\n";
    return 0;
}
預期輸出
1 0

未設定文字格式時，true 輸出為 1，false 輸出為 0。

2. if / else 在兩條路中選一條

先讀語法

if (條件) {
    條件成立時的敘述;
} else {
    條件不成立時的敘述;
}
#include <iostream>
int main() {
    int age = 20;
    if (age >= 18) {
        std::cout << "可以入場\n";
    } else {
        std::cout << "尚未達到年齡\n";
    }
    return 0;
}
預期輸出
可以入場

先計算小括號內的條件，只執行其中一個大括號區塊。需要更多情況時，可在中間加入 else if (條件)。本體只有一個敘述時可以省略大括號；本頁先保留它，讓範圍清楚。

3. &&、||、! 組合條件

&& 表示兩邊都成立，|| 表示至少一邊成立，! 把真假顛倒。

短路求值先看左邊

divisor != 0 && total / divisor > 5

若 divisor != 0 為 false，整個 && 已不可能成立，右側除法不會執行，因此避免除以零。|| 則在左側為 true 時略過右側。

#include <iostream>
int main() {
    int total = 30;
    int divisor = 0;
    if (divisor != 0 && total / divisor > 5) {
        std::cout << "結果大於 5\n";
    } else {
        std::cout << "條件不成立\n";
    }
    return 0;
}
預期輸出
條件不成立

4. switch 依一個值選 case

先讀語法

switch (值) {
    case 常數:
        敘述;
        break;
    default:
        敘述;
}
#include <iostream>
int main() {
    int choice = 2;
    switch (choice) {
        case 1: std::cout << "咖啡\n"; break;
        case 2: std::cout << "熱茶\n"; break;
        default: std::cout << "沒有這個選項\n";
    }
    return 0;
}
預期輸出
熱茶

break 離開 switch；省略時會繼續執行下一個 case。

5. while：不知道要重複幾次

先讀語法

while (條件) {
    重複的敘述;
    更新條件所需的值;
}
#include <iostream>
int main() {
    int saved = 0;
    while (saved < 100) {
        saved = saved + 40;
        std::cout << "存款：" << saved << "\n";
    }
    return 0;
}
預期輸出
存款：40
存款：80
存款：120

每輪開始前先檢查條件。若本體沒有讓條件逐步變成 false，可能永遠停不下來。

6. for：已知重複次數

先讀語法

for (初始化; 繼續條件; 每輪更新) {
    重複的敘述;
}
#include <iostream>
int main() {
    for (int day = 1; day <= 3; day++) {
        std::cout << "第 " << day << " 天\n";
    }
    return 0;
}
預期輸出
第 1 天
第 2 天
第 3 天

初始化只做一次；之後依序檢查條件、執行本體、更新，再回去檢查。第一次看到的 day++ 等同 day = day + 1。

互動：逐步執行 for

初始化 day = 1
檢查 day <= 3：true
輸出「第 1 天」，再做 day++
day = 2：檢查、輸出、更新
day = 3：檢查、輸出、更新
day = 4，條件 false，迴圈完成

尚未開始

7. break 與 continue

break 立刻結束最內層迴圈；continue 跳過本輪剩下的敘述，進入下一輪。

#include <iostream>
int main() {
    for (int number = 1; number <= 8; number++) {
        if (number == 3) {
            continue;
        }
        if (number == 6) {
            break;
        }
        std::cout << number << " ";
    }
    std::cout << "\n";
    return 0;
}
預期輸出
1 2 4 5

3 被 continue 略過；遇到 6 時 break 結束迴圈。

動手預測

把三天的迴圈條件改成 day < 3，會印出哪些天？

提示與答案

每輪開始前先檢查條件；day 等於 3 時不再進入，因此只印第 1 天與第 2 天。

P2 速查

比較產生 bool；if 選擇路徑；while 適合未知次數，for 適合已知次數；break 結束迴圈，continue 跳過本輪。
