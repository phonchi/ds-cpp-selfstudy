PART 01 · 固定陣列

把一組測量值排成有編號的一列

已知資料筆數時，可以用固定陣列保存同型別資料。宣告中的 5 是元素個數；索引從 0 開始，因此最後一格是 4。

語法拆解
#include <iostream>
using namespace std;  // 本例因此可省略 std:: 前綴

int main() {
    int temperature[5] = {18, 20, 21, 19, 24};
    int total = 0;
    for (int i = 0; i < 5; i++) total += temperature[i];
    cout << "第三筆 = " << temperature[2] << "\n";
    cout << "總和 = " << total;
}
預期輸出
第三筆 = 21
總和 = 102

temperature[i] 取得第 i 格。C++ 不會替原生陣列檢查索引，使用者必須確保索引位於有效範圍。

陣列不是指標

陣列是包含多個元素的物件；指標則是保存位址的變數。陣列名稱在許多運算式中會轉成首元素位址，但兩者仍不是同一種東西。

PART 02 · 位址與指標

指標保存「某個值放在哪裡」

&score 取得 score 的位址；int *p 宣告可指向 int 的指標；*p 沿著位址找到原本的整數。位址每次執行可能不同，所以範例只比較位址，不預測實際數字。

#include <iostream>
using namespace std;  // 本例因此可省略 std:: 前綴

int main() {
    int score = 72;
    int *p = &score;
    if (p == &score) {
        cout << "same address\n";
    } else {
        cout << "different\n";
    }
    *p = 85;
    cout << "score = " << score;
}
預期輸出
same address
score = 85
同一個 *，兩個位置

int *p 中的 * 是宣告的一部分；運算式 *p 則是解參考。只有指向仍有效物件的指標才能解參考。非空只表示位址數值不是空；懸空指標也可能非空，仍然無效。

互動 · 指標的值與指向狀態

下面改用一個獨立小例子，不延續上方把 score 改成 85 的例子：

int x = 42;
int *p = &x;
*p = 75;

按「播放」或「下一步」，觀察 p 從尚未建立到修改原值。

PART 03 · 空指標

nullptr 明確表示「目前沒有指向任何物件」

指標若暫時沒有目標，初始化為 nullptr。它可以拿來比較，但不能解參考。

#include <iostream>
using namespace std;  // 本例因此可省略 std:: 前綴

int main() {
    int *selected = nullptr;
    if (selected == nullptr) cout << "尚未指定測量值\n";
    int reading = 31;
    selected = &reading;
    if (selected != nullptr) cout << "讀值 = " << *selected;
}
預期輸出
尚未指定測量值
讀值 = 31

舊程式可能用 NULL 表示空指標；新程式優先使用型別更明確的 nullptr。不要執行 *selected，除非已確認它不是空指標。

PART 04 · 函式參數

用指標讓函式修改呼叫端的值

參數 int *value 接收整數位址。呼叫時傳入 &reading，函式內以 *value 修改原值。

#include <iostream>
using namespace std;  // 本例因此可省略 std:: 前綴

void calibrate(int *value) {
    if (value != nullptr) *value += 2;
}
int main() {
    int reading = 25;
    calibrate(&reading);
    cout << "校正後 = " << reading;
}
預期輸出
校正後 = 27

陣列參數一定要另外帶長度

以下 average 的前提是 length > 0；呼叫端不可傳入空資料。int data[] 寫在參數列時，函式接到的是首元素位址，沒有元素個數。這是陣列作為函式引數時的轉換；不能因此說陣列本身就是指標。

#include <iostream>
using namespace std;  // 本例因此可省略 std:: 前綴

double average(const int data[], int length) {
    int total = 0;
    for (int i = 0; i < length; i++) total += data[i];
    return static_cast<double>(total) / length;
}
int main() {
    int samples[4] = {12, 18, 20, 22};
    cout << "平均 = " << average(samples, 4);
}
預期輸出
平均 = 18
sizeof 不等於元素個數

sizeof expression 量出該物件或型別占用的儲存大小，單位是 byte。在陣列仍是陣列的範圍，可用 sizeof samples / sizeof samples[0] 計算元素數；這個式子不假設 int 一定是 4 bytes。傳進上述函式後，data 已是指標參數，不能再用同一招。

PART 05 · 生命週期

位址只有在原物件仍活著時才有用

區域變數只活到所屬大括號結束。若指標保存了一個已離開範圍的物件位址，它就成為懸空指標。

// 錯誤示意：不可執行
int *badAddress() {
    int local = 42;
    return &local;  // local 在函式結束時失效
}

這是用來辨識錯誤的片段，沒有 main()，也不應拿回傳值來解參考。安全做法是回傳數值，或在確實需要較長生命週期時使用動態配置。

PART 06 · 動態配置

用 new[] 練習動態配置

P5 的 vector 能自動管理可變數量資料，日常程式優先使用它。本節手動配置是為了看懂配置與釋放的配對。new int[count]{} 配置一排整數並回傳首元素位址；使用完畢必須以 delete[] 配對。單一物件則是 new int(值) 配 delete。

範例輸入
3
8 13 21

#include <iostream>
using namespace std;  // 本例因此可省略 std:: 前綴

int main() {
    int count = 0;
    if (!(cin >> count) || count <= 0) return 1;
    int *measurements = new int[count]{};
    int total = 0;
    for (int i = 0; i < count; i++) {
        if (!(cin >> measurements[i])) {
            delete[] measurements;
            return 1;
        }
        total += measurements[i];
    }
    cout << "總和 = " << total;
    delete[] measurements;
    measurements = nullptr;
}
預期輸出
總和 = 42
#include <iostream>
using namespace std;  // 本例因此可省略 std:: 前綴
int main() {
    int *value = new int(15);
    cout << "值 = " << *value;
    delete value;
    value = nullptr;
}
預期輸出
值 = 15
PART 07 · 常見錯誤

三條安全界線

錯誤原因正確習慣
解參考空指標沒有有效目標解參考前確認非空
new[] 配 delete配置與釋放形式不相配new[] 一律配 delete[]
釋放後繼續使用別名所有指向同處的指標都已懸空先釐清誰負責釋放，釋放後不再使用任何別名
設成 nullptr 只會改到那一個指標

若 p 與 alias 指向同處，delete p; p = nullptr; 不會讓 alias 同步變空。alias 仍保存舊位址，但已不可解參考，也不可再次釋放。
