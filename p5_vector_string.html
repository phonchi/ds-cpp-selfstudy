PART 01 · 宣告與初始化

先認識文字，再建立文字清單

string 是標準函式庫提供的文字型別，使用前要引入 <string>。字串內容放在雙引號中，例如 string item = "牛奶";；單一字元才使用單引號。

#include <iostream>
#include <string>
using namespace std;  // 本例因此可省略 std:: 前綴
int main() {
    string item = "牛奶";
    cout << "商品：" << item;
}
預期輸出
商品：牛奶

vector 是可增減的同型別清單

再引入 <vector>。vector<string> 中的 <string> 指定每一項都是文字；這是樣板的使用語法，樣板如何定義會留到 P9。

#include <iostream>
#include <string>
#include <vector>
using namespace std;  // 本例因此可省略 std:: 前綴
int main() {
    vector<string> items = {"牛奶", "麵包"};
    cout << items[0] << " " << items[1];
}
預期輸出
牛奶 麵包

大括號列出初始項目。索引從 0 開始，所以 items[0] 是第一項。

PART 02 · 大小與尾端增減

先問有幾項，再從尾端加入或移除

名稱.操作(參數) 是呼叫物件操作的語法：點號左邊是物件，右邊是標準函式庫替它提供的操作；例如 items.push_back("蘋果")。如何自己定義類別與操作會留到 P8。

size() 回傳目前項目數；push_back(value) 加到最後；pop_back() 移除最後一項，但不會把被移除的值傳回來。空清單不可呼叫 pop_back()。

#include <iostream>
#include <string>
#include <vector>
using namespace std;  // 本例因此可省略 std:: 前綴
int main() {
    vector<string> items = {"牛奶", "麵包"};
    items.push_back("蘋果");
    cout << "刪除：" << items[items.size() - 1] << "\n";
    items.pop_back();
    cout << "剩下 " << items.size() << " 項";
}
預期輸出
刪除：蘋果
剩下 2 項
PART 03 · 走訪

範圍 for 逐項處理，不必自己管理索引

for (string item : items) 每次把元素複製給 item，修改它不影響原清單。加上 & 成為 string& item，名稱便直接代表原元素。

#include <iostream>
#include <string>
#include <vector>
using namespace std;  // 本例因此可省略 std:: 前綴
int main() {
    vector<string> items = {"牛奶", "麵包"};
    for (string& item : items) {
        item += "!";
    }
    for (const string& item : items) {
        cout << "[" << item << "]";
    }
}
預期輸出
[牛奶!][麵包!]

auto 讓編譯器從初始值推得型別

auto first = items[0]; 中，右側是 string，所以 first 也是 string。它仍有固定型別，不代表可以任意換成別種資料。

for (const auto& item : items) {
    cout << item << "\n";
}

這是放在已建立 items 後面的片段；const auto& 表示只讀取原元素，不複製也不修改。

PART 04 · 完整文字

getline 讀取包含空白的一整行

cin >> word 遇到空白就停止；留言通常包含空白，因此使用 getline(cin, message)。把 getline 放在條件中時，讀取成功為 true，失敗為 false。字串可用 + 產生新字串，或用 += 接在原字串尾端。

範例輸入
今天記得帶雨傘
#include <iostream>
#include <string>
using namespace std;  // 本例因此可省略 std:: 前綴
int main() {
    string message;
    if (!getline(cin, message)) return 1;
    message += "！";
    cout << "留言：" << message;
}
預期輸出
留言：今天記得帶雨傘！
接在 cin >> 後面時

先前用 cin >> 讀整數，輸入中的換行可能還留著，下一個 getline 便會先讀到空行。若不需要保留行首空白，可寫成下面的短片段；ws 是略過前導空白與換行的標準操作。若行首空白也是資料，從一開始就使用整行輸入。

int count = 0;
if (!(cin >> count)) return 1;
string message;
if (!getline(cin >> ws, message)) return 1;
PART 05 · 搜尋與擷取

find 找位置，substr 取一段

text.find(part) 回傳第一次找到的起始位置；找不到時回傳 string::npos。text.substr(pos, count) 從 pos 開始取 count 個 char。

#include <iostream>
#include <string>
using namespace std;  // 本例因此可省略 std:: 前綴
int main() {
    string message = "bring rain coat";
    auto position = message.find("rain");
    if (position != string::npos) {
        cout << "找到 rain\n";
        cout << "摘要：" << message.substr(position, 4);
    }
}
預期輸出
找到 rain
摘要：rain

substr 的第二個參數以 char 為單位，不是結束位置。本例的英文字母與空白各占一個位元組，因此可直接用可見字元數計算；UTF-8 中一個可見中文字通常由多個位元組，也就是多個 char 組成，不能把 count 當成中文字數。使用搜尋結果前先確認它不是 string::npos。
